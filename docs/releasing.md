# Releasing

Releases are built by [dist](https://github.com/axodotdev/cargo-dist) on GitHub Actions.
Each release has prebuilt Windows x64 and Linux x64 binaries plus one-line installers,
so users don't need Rust. The dist settings are in `dist-workspace.toml`.

Install and update instructions for users are in the [README](../README.md#install).

## Cutting a release

1. Bump `version` in `Cargo.toml` (for example `0.2.0`) and run `cargo build`, so that
   `Cargo.lock` is updated too. Commit both and push to `main`.
2. Tag that commit with the same version, with a `v` in front, and push the tag:

   ```sh
   git tag v0.2.0
   git push origin v0.2.0
   ```

The tag has to match the version in `Cargo.toml`, or the release fails at the plan step.
A version with a suffix, like `v0.2.0-beta.1`, is published as a prerelease, which
`releases/latest` skips.

## What CI does

Nothing runs on pushes to `main` or on pull requests, to keep GitHub Actions usage down,
so run `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` and `cargo test`
locally before tagging.

`.github/workflows/ci.yml` checks formatting, runs clippy with warnings as errors, and
runs the tests, on Ubuntu 22.04 and Windows. It runs on version tags, alongside the
release build (a failure there doesn't stop the release), and can be run by hand from
the Actions tab ("CI", then "Run workflow").

`.github/workflows/release.yml` is generated by dist; don't edit it by hand. On a version
tag it:

1. builds the binaries: Linux on Ubuntu 22.04 (an older glibc, so the binary runs on
   more distros) and Windows with the C runtime linked statically (no
   `VCRUNTIME140.dll` needed)
2. builds the installer scripts, checksums and a source archive
3. creates the GitHub release for the tag and uploads everything to it.

After changing `dist-workspace.toml` or upgrading dist, run `dist generate` to rewrite
`release.yml`. Run `dist plan` to see what a release would contain, or
`dist build --artifacts=local` to build the archive for your own platform into
`target/distrib/`.
